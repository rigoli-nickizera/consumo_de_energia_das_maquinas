# ⚡ EnerControl
### ENERGIA SOB CONTROLE

**Sistema Web de Monitoramento e Gestão Energética**

O **EnerControl** é um projeto desenvolvido com o objetivo de monitorar o consumo de energia das máquinas de três setores de uma empresa, calcular custos energéticos em horários de ponta e fora de ponta, acompanhar metas mensais e gerar relatórios e alertas.

A solução busca identificar oportunidades de economia, reduzir desperdícios e promover uma gestão energética mais eficiente.

---

### 🎯 Objetivos do Projeto
- Monitorar o consumo de energia das máquinas.
- Calcular custos de acordo com os horários de consumo.
- Gerar relatórios e alertas sobre as metas mensais.
- Identificar oportunidades de economia energética.
