# ⚡ EnerControl — ENERGIA SOB CONTROLE

💡 **Controle inteligente, consumo consciente!**

O EnerControl é um sistema web desenvolvido para monitorar o consumo de energia das máquinas dos três setores da empresa, calcular custos energéticos, acompanhar metas mensais e gerar relatórios e alertas.

🎯 **Objetivo:** identificar oportunidades de economia, reduzir desperdícios e promover uma gestão energética mais eficiente e sustentável.

🔋 *Mais controle, menos desperdício, mais eficiência!*
